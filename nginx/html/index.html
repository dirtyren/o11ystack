1. Authentication & Access Controls

The root landing page (/) is publicly accessible without credentials. Individual backend services require either HTTP Basic Authentication or application-level tokens: 

Default Basic Auth: user=admin | password=(configured in .env / nginx/.htpasswd)

2. Quick Testing & Diagnostic Commands

Test VictoriaMetrics Instant Query:

curl -k -u admin:<BASIC_AUTH_PASSWORD> https://localhost/vmetrics/api/v1/query?query=up

Test VictoriaLogs LogSQL Search:

curl -k -u admin:<BASIC_AUTH_PASSWORD> -G 'https://localhost/vlogs/select/logsql/query' --data-urlencode 'query=*'

Query LiteLLM Models & Health:

curl -k https://localhost/litellm/health/readiness

Query Mezmo AURA Health Endpoint:

curl -k -u admin:<BASIC_AUTH_PASSWORD> https://localhost/aura/health
